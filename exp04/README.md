# Experiment 4: Video Data Preprocessing

## Dataset: UCF101

13,320 YouTube clips of 101 human actions. The notebook reads a 12-clip subset (TennisSwing, Basketball, PlayingGuitar) straight out of a hosted copy of the archive.

- Official page: https://www.crcv.ucf.edu/data/UCF101.php
- Copy used by the notebook: https://huggingface.co/datasets/quchenyuan/UCF101-ZIP

The dataset is public, so it is linked here rather than copied into this repository.

## Files

- `Exp04_Video_Data_Preprocessing.ipynb`: the experiment notebook, with outputs.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
