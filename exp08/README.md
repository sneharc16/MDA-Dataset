# Experiment 8: Video Summarization with Text and Visuals

A 24-second synthetic Tech Fest video (320 x 240, 10 FPS, 240 frames) with 8 scenes, its subtitles, and the ground truth marking the 3 key scenes.

## Files

- `Exp08_Video_Summarization.ipynb`: the experiment notebook, with outputs.
- `techfest.mp4`: the video.
- `techfest.srt`: 14 timed subtitle lines.
- `scenes_ground_truth.csv`: start and end of every scene and whether it is a key scene.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
