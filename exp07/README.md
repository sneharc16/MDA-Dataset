# Experiment 7: Named Entity Recognition and Document Ranking

A news-style corpus of 15 documents on Indian science, economy, sport, transport and weather, plus 5 search queries with hand-labelled relevant documents.

## Files

- `Exp07_Named_Entity_Recognition.ipynb`: the experiment notebook, with outputs.
- `documents.txt`: one document per line, `DOC_ID | TITLE | TEXT`.
- `queries.txt`: one query per line, `QUERY_ID | QUERY | RELEVANT_DOC_IDS`.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
