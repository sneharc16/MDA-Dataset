# Experiment 9: Document Ranking

An AI and ECE knowledge base of 30 short articles, 8 search queries and graded relevance judgements (2 = highly relevant, 1 = partially relevant).

## Files

- `Exp09_Document_Ranking_TFIDF_BM25.ipynb`: the experiment notebook, with outputs.
- `kb_documents.txt`: `DOC_ID | TITLE | TEXT`.
- `kb_queries.txt`: `QUERY_ID | QUERY`.
- `kb_qrels.txt`: relevance labels in TREC format, `QUERY_ID 0 DOC_ID GRADE`.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
