# Experiment 1: Text Data Preprocessing

Customer reviews prepared in Google Sheets with the columns `ReviewID` and `ReviewText`.

## Files

- `Exp01_Text_Data_Preprocessing.ipynb`: the experiment notebook, with outputs.
- `exp1_text_preprocessing.py`: the same code as a plain Python script.
- `reviews_1_entry.csv`: one review, used to show every preprocessing step on a single input.
- `reviews_5_entries.csv`: five reviews, used to build the vocabulary and compare TF-IDF weights.
- `reviews_5_entries.pdf`: the same five reviews exported from Google Sheets.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
