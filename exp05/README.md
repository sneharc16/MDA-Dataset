# Experiment 5: Multimodal Data Integration

36 caption and image pairs (12 per sentiment class) generated by the notebook. Image colour, brightness and texture follow the sentiment: warm and bright for positive, flat grey for neutral, dark and cold for negative.

## Files

- `Exp05_Multimodal_Data_Integration.ipynb`: the experiment notebook, with outputs.
- `dataset.csv`: caption text, image path and label for every sample.
- `mm_images/`: the 36 images (224 x 224, JPG).

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
