# Experiment 3: Audio Data Preprocessing

## Dataset: UrbanSound8K

8,732 labelled urban sound clips (up to 4 s) in 10 classes. The notebook downloads it through the `soundata` library.

- Official page: https://urbansounddataset.weebly.com/urbansound8k.html

The dataset is public, so it is linked here rather than copied into this repository.

## Files

- `Exp03_Audio_Data_Preprocessing.ipynb`: the experiment notebook, with outputs.
