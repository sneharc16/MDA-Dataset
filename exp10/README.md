# Experiment 10: Cross Modal Retrieval

800 images (96 x 96) of one object each, varying in shape, colour, size and position, with a paraphrased caption for every image. 600 pairs are for training and 200 for testing; purple star and yellow triangle appear only in the test set.

## Files

- `Exp10_Cross_Modal_Retrieval.ipynb`: the experiment notebook, with outputs.
- `xmodal_data/captions.csv`: image file, caption, shape, colour, size, position and split.
- `xmodal_data/images/`: the 800 PNG images.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
