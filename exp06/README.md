# Experiment 6: Emotion Recognition from Text and Audio

24 utterances (6 each for sad, neutral, angry, happy), each paired with a 2-second clip at 22,050 Hz synthesised from an emotion-specific voice profile (pitch, pitch glide, loudness, syllable rate, jitter).

## Files

- `Exp06_Emotion_Recognition_Text_Audio.ipynb`: the experiment notebook, with outputs.
- `dataset.csv`: utterance text, audio path and emotion label.
- `emotion_audio/`: the 24 WAV files.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
