# Experiment 2: Image Data Preprocessing

## Dataset: CIFAR-10

60,000 colour images of size 32 x 32 in 10 classes. The notebook loads it with `tensorflow.keras.datasets.cifar10`, so nothing needs to be downloaded by hand.

- Official page: https://www.cs.toronto.edu/~kriz/cifar.html

The dataset is public, so it is linked here rather than copied into this repository.

## Files

- `Exp02_Image_Data_Preprocessing.ipynb`: the experiment notebook, with outputs.

Part of the Multimodal Data Analysis (BAI-417) lab, IGDTUW. See the [main README](../README.md) for all experiments.
